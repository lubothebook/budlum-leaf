# BUDLUM LEAF · CORE AND SKIN · STUDY · 01 · THE PRIOR ART OF THE SPLIT

**Revision L.7 candidate · 2026-10-19 · Study seat**. This is a survey by web search. It is not a patent search and not legal advice. It changes no L.6.0 or L.6.1 decision.

## 1 · The verdict first

**The Split is not new.** Compute packs, wireless pixel links, thin clients, one-box displays and modular parts all exist and sell today. Ayaz asked for something new and unique. The honest answer is that the idea of a surface split from its hardware is old, and only a join is open. `[PUBLICATION]` rows below.

**The open join is narrow.** It joins a wallet Core, many zero-key Skins, a roaming Skin and a validator Core. No source here joins them. `[HYPOTHESIS]` A web search cannot prove absence. Gate CSG-1 tests it.

**A hardware wallet gives a warning.** Wallets own their screen because a host screen can lie about an amount. A Skin is a screen the Core does not own. The trust seat must solve it. See row 19.

## 4 · What the table shows

1. **The tethered pack is a mature class.** Rows 1, 2, 4 and 5 sell or sold. Magic Leap 1 is end of life, and the source says the tether did not survive.
2. **The wireless pixel link is proven.** Rows 3, 7, 8 and 9 use one. All sit within a few metres and most need a clear path.
3. **A panel that is only a panel is on sale.** The LG M3 has all circuitry in a box. Samsung One Connect does it by cable. `[PUBLICATION]`
4. **One box for many displays exists.** Row 14 has a quad-display zero client and row 15 has wall controllers. None carries a wallet.
5. **A zero-state display is a known idea.** The thin client source states that a lost device exposes little data. A zero-key Skin repeats that idea. `[PUBLICATION]` row 13.
6. **Part change in a core is old and fragile.** Ara had a hot swap cell and died. Fairphone sells it, and its core module is not a user part.
7. **Cross-year compatibility is the proven weak point.** Samsung boxes of one year do not fit the next year. `[HYPOTHESIS]` row 10, Search.
8. **The trusted screen is the wallet rule.** Row 19 says a hacked screen can change the amount. This cuts against a Skin that shows a signature request.
9. **Far compute is the oldest class of all.** Cloud XR, cloud gaming and cell-site compute run today. The device keeps a decoder and a display. Rows 21 to 24.
10. **A big far antenna can serve an unmodified small device.** Row 25 shows it, at hundreds of kbit/s. A slice stream needs a cell network.
11. **Cloud XR sets the C2 floor.** It asks `100` Mbps, `20` to `30 ms` and a wired server. `[PUBLICATION]` row 21. A Leaf slice stream is far smaller. `[HYPOTHESIS]`

## 6 · The join that remains open

| The element | The state of the art | The Split element |
|---|---|---|
| 1. one wallet Core | wallets exist but own their screen (row 19) | one Core holds every key for every Skin |
| 2. many zero-key Skins | zero clients hold no data but hold no wallet (row 13) | a Skin that cannot sign, and a lost Skin is glass |
| 3. a chain-attached Skin | no source found | the chain records the paired Core, and a Skin roams with its session |
| 4. the Core as a validator | no source found. Orion and Magic Leap use a private cloud or none | the room Core is a network node of Part 21 Section 21.5 |
| 5. one Core for a size family | wall controllers split one image over many cabinets (row 15) | one Core drives Leaf 80, 160, 480 and the Frame |
| 6. a part record on every part | Ara and Fairphone keep no portable record | a record lets a Core part change with no change to a Skin |

### 6.1 What is open for a claim at each distance class

| The class | What is old | What is open |
|---|---|---|
| C0, a tether to `2 m` | packs, tethers and one-box panels. Rows 1, 2, 5, 10 | one wallet Core with zero-key Skins, and a Skin that roams. Elements 1 to 3 |
| C1, a room to `30 m` | wireless panels and headsets. Rows 3, 7, 8, 9 | the same join. The Skin keeps a decoder, so "no processor" is false and "no key" stays true |
| C2, far to kilometres | cloud XR, cloud gaming, edge compute and a large far antenna. Rows 21 to 25 | the Core as a validator that also keeps the wallet session, with a zero-frame handover. Elements 3 and 4 only |

**At C2 the Split is not a hardware claim.** The Leaf is complete there. The claim moves to the network and the session. `[HYPOTHESIS]`

**The claim that can survive is the join of elements 1, 2 and 3.** One wallet Core, zero-key Skins and a Skin that roams. Elements 4 to 6 are design choices that add weight to it. `CLAIMS.md` words it.
