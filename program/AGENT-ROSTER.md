## 1 · The rotation rule

1. A sub-agent keeps its seat until it has finished at least `10` tasks. Ayaz set this number.
2. Until then the Lead sends the next task to the same agent, so its context stays.
3. After `10` tasks the Lead can replace the agent with a fresh one. The Lead writes a hand-over note first.
4. A task is one brief with one deliverable. A correction round on the same brief counts as one task.
5. The Lead never lets two agents write in the same directory.
