# BUDLUM LEAF · THE DIRECTIVE · PART 16 · THE GAP REGISTER

**What this part is**. The honest answer to the question *what is still missing.* Nothing on this list is hidden, and nothing on this list is called done. Each item carries a class, what it blocks, its owner line and the exact next action. `[DECISION]`

**The classes**. **B** a blocker: the next phase cannot start without it. **M** a major gap: it delays a phase or a claim. **m** a minor gap: it is planned and it does not block.

**The rule**. A gap is closed only by an artefact: a drawing, a code branch, a measurement or a signed document. A conversation closes nothing. `[DECISION]`
