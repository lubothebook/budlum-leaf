## 14.1 The glossary: one term, one meaning `[DECISION]`

| The term | The one meaning |
|---|---|
| **a Leaf** | the whole system: a surface, a cassette, a module, a wallet and a radio |
| **a member** | one member of the family: Leaf 80, Leaf 160, Leaf 160², Leaf 480, Leaf 1400, Leaf 2800, Leaf Frame |
| **the leaf** | one carried body: two faces and the cassette bay |
| **a face** | one side of a carried member |
| **a panel** | one P80 or one P160 glass-free panel |
| **a tile** | one T40 B or T40 C far tile |
| **the cassette** | the removable energy part, 2.88 mm |
| **the module** | the removable part with the cameras, the battery, the sound set, the pen dock and the jack, 4.00 mm |
| **the spine** | the perforated laminate that is the structure, the bus, the heat path, the antenna ground and the anchor |
| **the hub** | the fixed function controller: the decoder, the scheduler, the local renderer, the reprojection |
| **the local floor** | the functions that never wait for the network: the echo, the cursor, the safe screen, the wallet |
| **the class** | the measured capability of a link, stated on the surface |
| **the near validator** | a Budlum validator close to the user, which the user can own |
| **a lease** | the permission to read a sensor with a stated model, purpose, class set, expiry and retention |
| **a record** | the signed history of a part |
| **a manifest** | the signed geometry and capability description of a member |
| **the safe screen** | the hardware drawn state that works with no link, no wallet and no cassette |
| **the Field mode** | the stereo mode of a carried member with a spacer |
| **the clear panel** | the transparent emissive panel |
| **the dimmer** | the electrochromic layer of a clear panel |

## 14.5 The forbidden words, in one list

Forbidden claim terms: *all day*, *unbreakable*, *zero latency*, *no hardware*, *VR ready*, *metaverse*, and *a private display*. Forbidden device-class words: *phone*, *tablet*, *television*, *monitor*, *laptop*, *computer*, and any unverified superlative. `[DECISION]`

## 14.6 The one-page summary of the final directive

| The subject | The final answer |
|---|---|
| The product | a Budlum Leaf: a surface, a cassette, a module, a wallet and a radio |
| The family | Leaf 80, 160, 160², 480, 1400, 2800, the Frame, and the Field mode |
| The carried geometry | `80 x 160 x 2.00 mm` 4-Quadrant (`+`) T-OLED + PDLC + `LLZO` body (`R 3.20 mm`, `<15 µm` seam), `144 Hz`, `508 ppi` |
| The mass | **17 g** per quadrant (`40 x 80 x 2.00 mm`); **68 g** 4-Quadrant (`+`) body; **88 g** complete with the `20 g` `90°`-bent-stem B module |
| The runtime | `>14.1 h` active session on the `12.0 Wh` (`3 200 mAh`, `750 Wh/L`) `LLZO/PEO` solid-state battery at `0.85 W` Zero-CPU draw |
| The module and charging | `90°`-bent-stem B module (`20 g`, flat ring on screen, sole `USB-C` in stem) + portless `Qi2.2` (`15-25 W`) wireless charging on body |
| The shape | `80 x 160 x 2.00 mm` 4-Quadrant (`+`) `ISO 10993` polycarbonate + `T-OLED` + `LLZO` sheet (`R 3.20 mm`, `r 0.65 mm`) |
| The light | a flexible organic stack with a quantum dot layer; a clear variant for the Frame and the Window |
| The distance | the interaction is local and the processing is remote, with a stated deadline, a provisional local image and a mobile job |
| The heat | the heavy compute never enters the device; the module is buffered, spread and coupled; the leaf is the radiator |
| The network | Budlum is live; the near services belong to the validator role; no second system |
| The rules of the user | no read without a grant, no sensor without a lease, no model without a declaration, no key custody |
| The service | the user replaces the panel, the cassette and the module; five years of parts |
| The market | Turkey first, then the European Union |
| The program | three lines at once, a weekly beat, a living state, and a claim that needs a gate |

**The last sentence of the directive**. *The device answers because it is close to the hand. The network answers because it is verified, and a place to stand joins the two*. `[DECISION]`
